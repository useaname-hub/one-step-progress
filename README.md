# 成绩汇总工作台

纯浏览器端运行的高中成绩自动计算网页应用：**无需服务器、无需联网、双击即用**，所有数据只在本机浏览器内处理。

## 快速开始

- 方式一：双击 `index.html`（需要与 `assets/` 文件夹在一起）。
- 方式二：双击 `单文件版/成绩汇总工作台.html`（单个文件，方便拷给同事）。

推荐使用最新版 Edge / Chrome。

## 使用流程

1. **导入成绩**：拖入「本次考试」Excel（必填），可再拖入「上次考试」用于进退对比。
2. **学生管理**：核对清洗结果；可手动新增、删除学生；查看缺考 / 已删除名单。
3. **班级层次**：默认精英班 / 火箭班 / 实验班，可自由增删层次、调整班级归属。
4. **统计汇总**：年级总表、班级分表、班级均分统计、班级差值表（含班主任、代课教师，可导入教师表自动填充）。
5. **成绩分析**：选任意班级，查看应考/实考、总分均分与分数段、各科均分与层次名次，编辑文字板块；页面下方还有**全年级专项统计**（中考分组、剔除特定学生后汇算）。
6. **奖励名单**：分层等比例总分优秀 + 单科年级第一。
7. **导出**：一键下载全部、分模块下载、逐班导出。

配置（层次、教师、分析文字、奖励比例、考试名称）会自动保存在浏览器 `localStorage`，下次打开自动恢复；**成绩数据本身不保存**，刷新后需重新导入。

## 输入格式

支持两类常见导出格式，程序会在前 12 行内自动定位表头；**表头可以是一行，也可以是两行**（第一行「总分 / 语文 / 数学…」，第二行「等级 / 得分 / 年次 / 班次」）：

- **格式 A**（如现有 `高一成绩.xlsx`）：
  `学号 | 姓名 | 分班 | 总分 | 年次 | 班次 | 语文 | 年次 | 班次 | 数学 | …`
- **格式 B**（带等级列）：
  `学号 | 考号 | 姓名 | 班级 | 语文等级 | 语文得分 | 语文年级位次 | 语文班级位次 | … | 总分等级 | 总分得分 | 总分年级位次 | 总分班级位次`

规则：

- 工作表名含「年级 / 总表」的作为基准表；其余作为班级分表；只有一张表时按总表处理。
- 「等级」列会被忽略（不输出）；「得分 / 年级位次 / 班级位次」会被识别。
- 缺考（状态含缺考/未考/未上传/免考，或全部学科为空）整行删除；以基准表学号为唯一依据。
- 班级分表中出现、但基准表没有的学生会被剔除并记入质检清单。

## 计算规则

- **列顺序**：学号、考号、姓名、班级，之后依次为 总分、语数外总分、语文、数学、英语、物理、化学、生物、历史、地理、政治；每个计分项后跟「年级位次、班级位次、位次进退」。
- **总分**：源表有则采用，否则由九科求和；**语数外总分** = 语文 + 数学 + 英语。
- **排名**：标准 RANK，同分并列、跳号（1,1,3）。
- **进退** = 上次年级位次 − 本次年级位次；正数为进步，负数为退步，0 为持平；上次没有该学生显示「新进」。
- **班级均分**：按班级条件求平均；给出年级班级排名与层次内排名。
- **差值表**：本班均分 − 本层次均分；每组末尾有「平均」行；教师列可编辑。
- **分数段**：默认 ≥850、800–850、750–800、700–750、650–700、600–650、550–600、500–550、<500，可在 `assets/core.js` 的默认值或页面配置中调整。
- **奖励**：各层次按同一比例取总分前 p%，默认 16.7%（约 200 人）；单科第一同分并列全部列出。

## 班主任 / 代课教师（差值表）

在「统计汇总 → 班级差值表」点「导入班主任 / 教师」，支持三类表，自动识别：

1. **宽表**：`班级 | 班主任 | 语文 | 数学 | 英语 | 物理 | 化学 | 生物 | 历史 | 地理 | 政治`，每行一个班。
2. **长表**：`班级 | 学科 | 教师 | 职务`，职务为「班主任」的写班主任，其余写代课教师。
3. **纯班主任表**：`班级 | 姓名` 或 `班级 | 班主任`。

班级写 `1`、`1班`、`高一1` 都能识别；学科写 `语文` 或 `语文教师` 都行。

也支持学校常用的「教师名单」式：`姓名 | 职务 | 学科 | 行政班`，职务写「班主任」或「学科教师」，行政班可写多个班（如 `2,3,4,6`），程序会按班级展开。导入后差值表会出现「班主任」列与每个学科后的「代课教师」列，也可手动改，保存到浏览器。

## 全年级专项统计（中考分组 / 剔除）

在「成绩分析」页下方：

1. 点「导入学生信息（中考 / 类别）」，选择 Excel。需要的列：
   - **学号**（必需，与成绩表一致）
   - **中考总分**（必需，数值）
   - **类别**（可选，如 子弟、休返、正常，可自由填写）
2. 也可以把「中考总分」「类别」两列直接加进年级总表，导入成绩时自动识别。
   学生档案里有多个 Sheet（如「学生档案」+「待补分」）也可以直接导入，按学号合并、保留非空的中考分数。
3. 两条线可改：**本校录取线（默认 688）**、**对比校线（默认 699）**。分别输出「688 及以上 / 688 以下」「699 及以上 / 699 以下」四组，另加「未录入中考」与「全年级（剔除后）」；每组含人数、占比、中考均分、本次总分均分/最高/最低、语数外及九科均分。
4. 剔除做成**逐人勾选**：列出全部子弟 / 休返学生，默认勾选「休返」和「没有中考分数的子弟」（有中考分数的子弟默认保留）；可单人改，也可「休返全选 / 全不选」「子弟全选 / 全不选」「恢复默认」，其他学生可搜索后加入。
5. 剔除后输出「全体 / 剔除后 / 被剔除 / 差值」四列，全年级口径，不按班级拆分。

> 若只有中考各科分数，没有中考总分，请告诉我各科满分，我来加总；或先在表里加一列总分。

## 导出（按文件选择）

导出页按「一个模块一个文件」列出，勾选后批量下载，也可单独下载某一个：

`年级总表`、`进退分析`、`班级分表（可勾选班级）`、`班级均分`、`班级差值表`、`总分优秀`、`单科第一`、`成绩分析`、`分数段统计`、`中考分组统计`、`中考未录入`、`剔除后统计`、`剔除名单`、`缺考名单`、`数据质检`。

- 默认勾选除「班级分表」外的模块；班级分表默认不勾，勾选后可**按班多选**（全选/全不选），每个班单独生成一个文件，不会把多个班塞进一个工作簿。
- 班级分表可另选「含成绩分析」「含分数段统计」；不勾时每个班文件只有一个成绩 sheet，勾选后在该班文件内追加对应工作表。
- 分数显示规则：整数分不补小数（846），含小数的保留两位（853.50）；Excel 里只对含小数的单元格设 `0.00` 格式，值仍是数字，可继续排序/计算。
- 「下载选中」逐个生成文件；仍保留「合并为一个工作簿」用于整份存档。
- 主表表头：每个计分项后依次为「班次、班次进退、级次、级次进退」（分数 → 班级位次 → 班级进退 → 年级位次 → 年级进退）；均分表为「总分 | 年级排名 | 层次排名」。
- 差值表导出按模板做成两行合并表头：`班级 | 总分（班主任/总分/排名/差值/上次名次/进退）| 语数外（均分/排名/差值/上次名次/进退）| 语文…政治（均分/排名/差值/上次名次/进退/教师）`；按层次分组，组末一行「平均」，不再单列「层次」。
- 所有文件表头一行、白底无填充，数值为真实数值，WPS / Excel 均可打开。

## 文件结构

```
成绩汇总工作台/
  index.html                 主页面
  assets/
    styles.css               样式
    core.js                  解析、清洗、排名、统计（纯函数，可 Node 测试）
    app.js                   界面与导出
    xlsx.full.min.js         SheetJS（本地）
  单文件版/
    成绩汇总工作台.html      所有代码内联的单文件版本
  samples/                   测试样例（含真实成绩副本，分发前请删除）
  tests/                     Node 测试脚本
  设计说明.md
  README.md
```

## 本地测试

```powershell
node tests/validate-real.cjs samples/高一成绩.xlsx   # 用源表自带的年次/班次校验排名（12010 项全对）
node tests/dom-test.cjs                              # 模拟浏览器：导入→各页渲染→生成工作簿
node tests/dom-test2.cjs                             # 多表 + 缺考 + 插班生 + 上次考试进退
```

> 测试依赖 `jsdom`，仅在开发时使用；应用本身零依赖、可离线运行。

## 隐私

页面不发起任何网络请求，不上传文件；关闭页面后成绩数据即从内存释放。
